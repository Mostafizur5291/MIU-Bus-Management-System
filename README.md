# MIU Bus Management System 🚌

A web-based bus management and route tracking system designed for students of **Manarat International University (MIU)** traveling on the **Rampura to Ashulia Campus** route.

## 🌟 Key Features
- **Student Authentication**: Secure login/registration system using Student ID, Name, and Gmail.
- **Gender-Based Bus Filter**: Dedicated selector for Male Bus (Bus-1) and Female Bus (Bus-2).
- **Driver Contact Info**: Quick access to contact information for bus drivers.
- **Live Location Status**: Real-time status update indicator for the active route.
- **Trip Schedules**: Clear schedule for morning departure (07:10 AM) and return trips (01:45 PM & 05:05 PM).
- **Interactive Stoppage List**: Sequential breakdown of all 24 stoppages from Rampura Bridge to Campus.

## 🛠️ Tech Stack
- **Frontend**: HTML5, Tailwind CSS, JavaScript (ES6)
- **Icons**: FontAwesome
- **Storage**: Browser LocalStorage
